# 📱 Day 35 - Rain Alert SMS App (Work in Progress)

A Python project that checks the weather forecast using the OpenWeatherMap API and was intended to send an SMS notification using Twilio if rain is expected.

> **⚠️ Project Status:** Incomplete  
> Twilio's free trial and API behavior have changed since this course was originally created. As a result, the SMS notification feature no longer works in the same way, making it difficult to fully complete the project without a paid Twilio account or an alternative SMS service.

---

## 📖 Overview

The goal of this project was to build a simple weather alert system that:

- Fetches weather forecast data from the OpenWeatherMap API.
- Checks whether rain is expected within the next few hours.
- Sends an SMS reminder to carry an umbrella.

Although the weather-checking logic is functional, the SMS notification could not be completed due to changes in Twilio's service and free-tier limitations.
