# Day 29 - Password Manager (GUI with Password Generator)

## 📌 Overview
On Day 29 of the **100 Days of Code: Python Bootcamp**, I significantly improved my **Password Manager** by adding a password generator and enhancing the user experience with input validation and confirmation dialogs.

The application now allows users to generate strong random passwords, automatically fills the password field, validates user input before saving, and stores credentials safely in a text file after confirmation.

---

## 🚀 Concepts Practiced

- Tkinter GUI development
- Creating and managing Labels, Buttons, Entries, and Canvas
- Grid layout management
- Event handling with button commands
- Using the `random` module
- Generating secure passwords
- Working with lists and list comprehensions
- Shuffling data using `random.shuffle()`
- File handling with append mode
- Using `messagebox` for dialogs
- Input validation
- Clearing input fields after saving
- Functions and modular programming

## 💻 Features

- 🔐 Generate strong random passwords
- 🌐 Save website credentials
- 📧 Default email/username field
- ⚠️ Prevent saving when required fields are empty
- ✅ Confirmation popup before saving credentials
- 💾 Store passwords in `data.txt`
