## 📖 About This Repository

This repository documents my progress through the **100 Days of Python Bootcamp**.

The goal of this challenge is to become a proficient Python developer by building real-world projects while learning programming fundamentals, object-oriented programming, GUI development, data handling, APIs, automation, and much more.

Rather than simply completing exercises, I'm treating each day as a portfolio project by documenting what I learned and publishing the source code.
