## 📖 About This Repository

This repository documents my progress through the **100 Days of Python Bootcamp**.

The goal of this challenge is to become a proficient Python developer by building real-world projects while learning programming fundamentals, object-oriented programming, GUI development, data handling, APIs, web scraping, automation, and much more.

Rather than simply completing exercises, I'm treating each day as a portfolio project by documenting what I learned and publishing the source code.

# 💻 How to Run

Clone the repository:

```bash
git clone https://github.com/your-username/100-Days-of-Python.git
```

Navigate into any project folder:

```bash
cd Day-50-Auto-Tinder-Swipe-Bot
```

Run the project:

```bash
python main.py
```

Some projects require additional Python packages, API keys, credentials, or environment variables.

Check the individual project README for project-specific setup instructions.
