# Day 45 – Beautiful Soup & Web Scraping

## Overview

Day 45 of the **100 Days of Code – The Complete Python Pro Bootcamp** focused on **web scraping with Beautiful Soup**.

The main goal was to learn how to retrieve information from websites, parse HTML, and extract specific elements from a webpage using Python.

## Concepts Practiced

- Web scraping
- `requests` library
- `BeautifulSoup`
- Sending HTTP GET requests
- Parsing HTML
- Finding HTML elements
- `find()`
- `find_all()`
- HTML tags and attributes
- CSS classes
- Extracting text with `.text`
- Using loops to process scraped data
- Working with scraped data in Python
