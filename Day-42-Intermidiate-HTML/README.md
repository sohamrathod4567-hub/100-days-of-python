# Day 42 – Intermediate HTML

## Overview

On Day 42 of the **100 Days of Code – The Complete Python Pro Bootcamp**, I continued learning web development by exploring **Intermediate HTML**.

The focus was on creating more structured and meaningful HTML pages using elements such as lists, tables, forms, images, links, and other HTML features.

## Concepts Practiced

- HTML document structure
- Ordered and unordered lists
- Nested lists
- HTML tables
- Table rows and columns
- Table headers
- Forms
- Input elements
- Buttons
- Labels
- Links and navigation
- Images
- HTML attributes
- Semantic HTML structure

## How to Run

1. Download or clone this repository.
2. Navigate to the Day 42 project folder.
3. Open the `.html` file in a web browser.
4. Alternatively, use **VS Code with Live Server** to preview the webpage.

## Example

A basic HTML form:

```html
<form>
  <label for="name">Your Name:</label>
  <input type="text" id="name" name="name" />

  <button type="submit">Submit</button>
</form>
```

## What I Learned

Today I learned how to build more structured and interactive HTML pages. I also gained a better understanding of how HTML forms, tables, lists, and input elements are used to organize and collect information on websites.

This was another step toward building complete websites instead of only working with Python-based applications.
