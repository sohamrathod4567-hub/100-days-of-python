# Day 44 — Intermediate CSS

## Overview

Day 44 of the **100 Days of Code — Python Bootcamp** focuses on **Intermediate CSS**.

In this project, I practiced more advanced CSS concepts to improve the structure, appearance, responsiveness, and overall design of web pages.

## Concepts Practiced

* CSS selectors
* CSS specificity
* Inline, internal, and external CSS
* The CSS Box Model
* `margin`, `padding`, and `border`
* Width and height
* `display` properties
* CSS positioning
* `z-index`
* Floating elements
* Responsive design basics
* Media queries
* CSS layouts
* Combining multiple CSS properties to create structured designs

## How to Run

1. Clone or download the repository.
2. Navigate to the Day 44 project folder.
3. Open the HTML file in a web browser.

No additional dependencies are required.

## Example

The project demonstrates how HTML elements can be styled and positioned using intermediate CSS techniques.

```css
.container {
    width: 80%;
    margin: auto;
    padding: 20px;
}

@media (max-width: 768px) {
    .container {
        width: 95%;
    }
}
```

## What I Learned

Through this project, I improved my understanding of how CSS controls the layout and visual appearance of a webpage. I also learned how different CSS properties interact with each other and how responsive techniques can be used to make websites work across different screen sizes.
