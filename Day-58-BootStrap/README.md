# Day 58 - Bootstrap

## Overview

Day 58 focused on learning Bootstrap, a popular CSS framework used to build responsive and modern websites efficiently.

I learned how Bootstrap's grid system, utility classes, components, and responsive features can be used to create layouts with less custom CSS.

As a practical project, I built a TinDog landing page using Bootstrap.

## Concepts Practiced

- Bootstrap 5
- Bootstrap CDN
- Bootstrap Grid System
- Containers
- Rows and Columns
- Responsive Design
- Bootstrap Utility Classes
- Flexbox Utilities
- justify-content-center
- text-center
- Responsive Images
- Bootstrap Buttons
- Navigation Bars
- Bootstrap Icons
- Responsive Typography
- Combining Bootstrap with Custom CSS

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## How to Run

1. Clone the repository:

   git clone <your-repository-url>

   cd Day-58

A responsive landing page for a fictional dating platform for dogs.
