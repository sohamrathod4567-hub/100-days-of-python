## How to Run

1. Open the project folder.
2. Open the HTML file in a code editor such as VS Code.
3. Open the `.html` file in a web browser.

You can also use the **Live Server** extension in VS Code to preview the webpage while developing.

## Example

A basic HTML page:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Website</title>
</head>

<body>
    <h1>My Website</h1>

    <p>This is my first HTML webpage.</p>

    <h2>My Hobbies</h2>

    <ul>
        <li>Coding</li>
        <li>Gaming</li>
        <li>Sports</li>
    </ul>

    <a href="https://www.google.com">Visit Google</a>
</body>
</html>
```
